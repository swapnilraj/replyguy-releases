# replyguy releases

Installers for the replyguy desktop app. The app checks this repo for updates and installs them itself. The source code is private.

## Download

Get the latest version from [Releases](https://github.com/swapnilraj/replyguy-releases/releases/latest):

| System | File |
|---|---|
| macOS | `replyguy-<version>-arm64.dmg` (Apple silicon) or `-x64.dmg` (Intel) |
| Windows | `replyguy-Setup-<version>.exe` |
| Linux | `replyguy-<version>.AppImage` (updates itself), or `.deb` / `.rpm` |

After installing, open replyguy and follow the Setup screen to add its browser extension.
